## 0. 이 문서 읽는 법

- 굵게 쓴 글자(예: **저장소 열기**)는 앱 화면에 보이는 글자 그대로입니다. 단추·메뉴·대화상자 제목을 찾을 때 그 글자를 찾으면 됩니다. 굵은 글자는 화면 글자에만 씁니다. `<이름>` 처럼 꺾쇠로 싼 부분에는 실제 이름이나 숫자가 들어갑니다.
- 화면 글자는 한국어 화면 기준입니다. 화면을 영어로 쓰면 글자가 다르게 보입니다. 화면 언어는 [8.11 언어](사용법/8-설정.md#811-언어)에서 바꿉니다.
- 단축키는 Mac 기호로 적습니다.

  | 기호 | 키      |
  | ---- | ------- |
  | ⌘    | Command |
  | ⇧    | Shift   |
  | ⌥    | Option  |
  | ⌃    | Control |

  예를 들어 `⌘⇧P` 는 Command 와 Shift 를 누른 채 P 를 누르는 것입니다.

- 알림 상자는 세 가지입니다.

  > [!NOTE]
  > 참고 — 알아 두면 좋은 사실이나 한계입니다.

  > [!TIP]
  > 요령 — 더 빨리 하는 방법입니다.

  > [!WARNING]
  > 주의 — 이력이나 파일이 예상과 다르게 바뀌거나, 되돌리기 어려운 동작입니다.

- mGit 은 탭을 두 가지로 엽니다. 여러 저장소가 든 폴더를 열면 **폴더 탭**, 저장소 하나를 열면 **저장소 탭**입니다. 두 탭은 화면 틀이 같지만 쓸 수 있는 기능이 조금 다릅니다. 차이는 [3.10 폴더 탭과 저장소 탭의 차이](사용법/3-화면-둘러보기.md#310-폴더-탭과-저장소-탭의-차이)에 모아 두었습니다.
- 그림은 합성 데이터로 띄운 화면입니다. 그림 속 경로(`/mock/…`)·저장소 이름·사람 이름은 모두 예시입니다. 본문의 예시 경로(`~/work/acme-platform` 등)도 가상입니다.
- 메뉴 막대는 따로 없습니다. "메뉴"는 커맨드 팔레트(`⌘⇧P`), 툴바 단추, 우클릭 메뉴 셋 중 하나입니다.

## 처음 10분

여러 저장소가 든 폴더 하나를 열어 변경을 commit 하고 push 하기까지의 길잡이입니다.

1. 설치 — git 2.45 이상이 있는지 확인하고 앱을 설치합니다. → [1.1 요구 사항](사용법/1-설치와-첫-실행.md#11-요구-사항), [1.2 앱 설치하기](사용법/1-설치와-첫-실행.md#12-앱-설치하기)
2. 폴더 열기 — 툴바의 **저장소 열기**를 누르고, 저장소들이 든 상위 폴더(예: `~/work/acme-platform`)를 고릅니다. 폴더 탭이 열립니다. → [2.1 여러 저장소가 든 폴더 열기](사용법/2-저장소와-폴더-열기.md#21-여러-저장소가-든-폴더-열기)
3. 둘러보기 — 왼쪽 Project 트리, 가운데 개요 탭, 아래 Git 도구 창의 통합 로그를 봅니다. → [3.1 화면 영역](사용법/3-화면-둘러보기.md#31-화면-영역)
4. 변경 보기 — 바뀐 파일은 Project 트리에서 색과 상태 문자로 보입니다. 왼쪽 띠의 **Commit**(`⌘0`)을 열면 저장소별 변경 목록이 나옵니다. → [4.1 변경 확인하기](사용법/4-일상-작업.md#41-변경-확인하기)
5. commit — Commit 도구 창에서 올릴 파일을 체크하고 메시지를 적은 뒤 **Commit** 을 누릅니다. → [4.2 stage 하고 commit 하기](사용법/4-일상-작업.md#42-stage-하고-commit-하기)
6. push — 툴바의 **Push** 를 누르고, 보낼 저장소를 체크해 확인합니다. → [4.3 Fetch·Pull·Push 하기](사용법/4-일상-작업.md#43-fetchpullpush-하기)

> [!TIP]
> 저장소 하나만 깊게 다루려면(stash, Undo, tag 등) 개요 탭에서 그 저장소 줄을 더블클릭해 저장소 탭으로 여세요. → [2.2 저장소 하나 열기](사용법/2-저장소와-폴더-열기.md#22-저장소-하나-열기)
