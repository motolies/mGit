# 매뉴얼 집필 중 발견한 문제

사용자 매뉴얼(`README.md`, `docs/`)을 코드와 대조하며 쓰는 동안 찾은 앱·빌드 쪽 문제입니다. 문서는 앱의 지금 동작대로 썼고, 앱 코드는 고치지 않았습니다. 후속 작업의 후보 목록입니다.

기준: 브랜치 `feat/intellij-workspace` · 2026-11-20 · 매뉴얼 커밋 `528b84b`(U0) ~ U7

- "슬라이스"는 그 문제를 찾은 집필 단계입니다(U1 = 사용법 1~3장, U2 = 4장, U3 = 5장, U4a = 6·8장, U4b = 7·9·10장, U5 = 빌드·테스트, U6 = 패키징).
- "확인 필요"는 코드로만 추론했고 실제 Mac 에서 재현하지 않은 것입니다.
- 내용 칸 앞의 `해결 <커밋>` 은 브랜치 `feat/multirepo-editor-batch1`(2026-11-26)에서 고친 항목입니다. 표시가 없는 항목은 그 브랜치에서 다루지 않았습니다(그 전에 고쳐졌을 수는 있습니다).
- 근거 경로는 `apps/desktop/src`·`crates` 등 저장소 기준입니다(짧게 쓴 것은 파일 이름으로 찾으면 됩니다).
