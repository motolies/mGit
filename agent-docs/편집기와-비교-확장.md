# 편집기와 비교 확장

## 사용 방법

- 브랜치 우클릭에서 현재 브랜치, 현재 로컬 내용 또는 upstream과 비교합니다. 비교 결과는 편집기 탭으로 열립니다.
- 로그에서 기준 커밋을 선택한 뒤 다른 커밋을 우클릭하면 두 커밋 시점을 비교합니다. 기존 연속 범위의 변경 합산과는 별도 동작입니다.
- 비교 탭에서 기준·대상과 공통 조상 기준을 선택하고 새로고침합니다. 로컬 비교는 미저장 초안과 새 파일을 포함하며 무시된 미추적 파일은 제외합니다.
- 두 커밋을 비교할 때 커밋 차이를 펼치면 각 시점에만 있는 커밋이 나타납니다. 한쪽당 최근 200개까지 표시하며 잘림 여부를 알립니다.
- 편집기 우클릭에서 현재 줄 Blame, 전체 Blame, 변경 표시를 전환합니다. 전역 기본값은 설정에서 변경합니다.
- `⌘⌥L` 또는 파일 포맷 버튼으로 현재 파일을 포맷합니다. 웹·설정·Java 포맷터는 앱에 포함됩니다. 목표 줄 길이는 기본 200이며 화면의 줄바꿈 설정과 별개입니다.
- 명시적 저장 시 포맷은 설정에서 선택합니다. 입력 후 자동 저장에는 포맷을 적용하지 않습니다. 포맷 결과는 한 번에 실행 취소할 수 있습니다.
- `⌘P`로 파일명·상대 경로를 검색하여 파일을 엽니다.
- `⌘⌥F`로 워크스페이스 내용 검색을 엽니다. 저장소 범위·경로·정규식·대소문자 옵션을 선택하고 결과를 누르면 해당 위치로 이동합니다. 열린 파일의 미저장 초안도 검색합니다.

## 구현 경계

비교와 검색은 저장소·폴더 세션의 루트로 초안 경로를 변환합니다. 파일 저장 큐와 CodeMirror 문서·실행 취소 이력은 기존 구조를 사용합니다. 비교 과정에서 작업 파일이나 인덱스를 변경하지 않습니다.

원격 비교는 fetch로 받은 원격 추적 참조를 사용합니다. 비교 탭의 Fetch 후 다시 비교 동작으로 갱신합니다. 알려진 fetch 시각이 없으면 확인 시각 없음으로 표시합니다.

검색은 Rust 내부에서 수행합니다. 외부 검색 프로그램 설치가 필요하지 않습니다. 후보 파일 100,000개·검색 결과 2,000개의 상한과 취소 기능이 있습니다. 저장소 범위를 선택해도 후보 탐색은 워크스페이스 전체를 순회할 수 있습니다.

Prettier standalone, Java 플러그인과 WASM 파서는 로컬 번들에서 실행합니다. 프로젝트의 외부 포맷터나 실행형 설정을 자동 실행하지 않습니다. IntelliJ와 완전히 동일한 Java 코드 스타일을 보장하지 않습니다.

## 검증 기록

검사 로그와 브라우저 CSP 검증 결과는 로컬 `target/feature-checks/`에 저장합니다. 이 폴더는 Git에 포함하지 않습니다. 버전·커밋·릴리스 게시 작업은 수행하지 않습니다.

- `pnpm check`: lint·타입 검사·테스트 195개 파일/2,339개 통과했습니다.
- `pnpm -F @mgit/desktop build:web`: 배포 웹 번들 빌드를 통과했습니다.
- `cargo fmt --all --check`, 워크스페이스 Clippy `-D warnings` 검사를 통과했습니다. 마지막 literal pathspec 보완도 해당 대상 Clippy와 실제 Git 테스트 11개로 검증했습니다.
- 실제 Git 테스트로 초안 덮어쓰기, 신규·무시·이름 변경 파일, 디스크/index 보존, 두 방향 커밋 목록과 특수문자 파일명을 확인했습니다.
- 브라우저에서 빠른 열기·내용 검색·로컬 비교 진입을 확인했습니다.
- 배포 번들과 실제 production CSP를 적용한 macOS WKWebView에서 Java 클래스·record·TypeScript 포맷이 성공했습니다. 이는 WebKit Worker·WASM 호환성 검증이며, Tauri 앱의 모든 화면에 대한 수동 검증을 의미하지 않습니다.
- Rust 전체 검사에서 코어·벤치 테스트가 통과한 뒤 기존 CSP 고정 기대값 2개를 새 정책에 맞게 보완했습니다. 이후 `cargo test --workspace --exclude mgit-core --exclude mgit-bench`로 나머지 패키지의 단위·통합·문서 테스트가 모두 통과했습니다. 마지막 코어 변경은 별도 실제 Git 회귀 검사로 확인했습니다.
